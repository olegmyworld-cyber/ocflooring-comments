# OC Flooring — Blog / 404 / Sitemap Audit (2026-08-24)

Audit of `nwocflooring.com` (Webflow site `6377e8e6a53936b48ef1cad0`) covering all
blog posts, sitemap health, dead (404) URLs and redirects. Sources: Webflow Data
API (CMS items, pages, sitemap-inclusion flags), Google Search Console (last 3
months, via Windsor.ai) and GA4 property "OC Flooring 2023" (last 3 months).

## What is healthy

- **All 109 blog posts** are published — no drafts, no archived items, no
  duplicate slugs. All 109 have `includeInSitemap: true` (live).
- **Sitemap**: `https://www.nwocflooring.com/sitemap.xml` in GSC shows
  **450 URLs submitted, 0 errors, 0 warnings**; Google last downloaded it on
  2026-08-24. No action needed.
- **Internal links inside blog posts**: 120 unique hrefs checked — **0 broken**.
  Every `/blog/...` link matches an existing slug; every `/city-of-*`,
  `/seattle/*`, `/services/*` link resolves to an existing page (note: Bothell
  city pages live under the folder `/hardwood-floor-refinishing/`, so links like
  `/hardwood-floor-refinishing/hardwood-floor-repair-in-bothell-wa` are correct).
- **Images in posts**: all 90 unique image srcs are on Webflow's CDN
  (`cdn.prod.website-files.com`).
- **Blog categories**: all 7 published; category pages resolve.
- **Canonical host**: GSC shows no `http://` or non-www variants being indexed.

## The problem: 272 dead URLs still getting search traffic

Google still serves **138 URLs that no longer exist** on the site (old page
slugs, deleted laminate/carpet/tile city pages, renamed blog posts, removed
products). Over the last 3 months these got **~39,000 impressions and 48
clicks** in Google Search — every click landed on the 404 page.

GA4 confirms these are live 404s (not redirects): **821 pageviews (~10% of all
site pageviews)** were recorded on non-existent paths. If redirects existed, GA4
would report the destination page instead.

## The fix: import `webflow-301-redirects.csv`

`webflow-301-redirects.csv` in this folder contains **272 validated redirect
rules** (`old path, new path`), sorted by traffic. Every target was verified to
exist on the current site; there are no self-redirects and no chains.

The site is not on a Webflow Enterprise plan, so redirects cannot be created via
API — they must be added in the Webflow dashboard:

1. Webflow → the OC Flooring site → **Site settings → Publishing → 301 redirects**.
2. Use the CSV import if available on the plan (upload the file as-is: column 1 =
   old path, column 2 = redirect to path, no header row), or paste rules
   manually starting from the top of the file (it is sorted by impressions, so
   the first ~40 rows cover ~80% of lost traffic).
3. Publish the site.

`redirects-with-traffic-data.json` carries the same rules with the GSC
impressions/clicks and GA4 pageviews per URL, for prioritizing.

## Minor observations (no action required)

- `/flooring-calculator` is the only page excluded from the sitemap
  (`includeInSitemap: false`) — fine if intentional.
- The Bothell city folder is slugged `/hardwood-floor-refinishing/` instead of
  `/city-of-bothell/`. Links work, but people (and Google) sometimes guess
  `/city-of-bothell/...` — those URLs are covered in the redirect CSV. Renaming
  the folder is possible but would require redirecting all 8 Bothell pages, so
  leaving it as-is is reasonable.
- 41 of 109 blog posts had zero Google impressions in the last 3 months — all
  are older posts; every post published since May 2026 is already getting
  impressions. A content-consolidation pass could help, but nothing is broken.
- The `changelog` page is in the sitemap; consider excluding it if it is
  internal.
